ShoppingCart project is an example of an e-commerce clothes website.

Its funcitonality is simple:
    1. You can view products(male or female)
    2. You can view a specific product, choose its size and add it to a cart
    3. Manipulate added to cart products in the cart

There are three main parts of this project:
    1. Front-end
    2. Back-end
    3. Database

Front-end and Back-end are docker image services that are ran on Azure Container App. For the database, Azure SQL server was used.

The correspoding README for Front-end and Back-end files can be found at /ShoppingCart-Frontend/README.md and /api/README.md respectively
